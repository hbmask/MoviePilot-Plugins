# 飞牛定向刷新

入库后（MoviePilot 下载整理完成）自动刷新飞牛影视对应的媒体库，非全量扫描。

## 原理

- 复用系统「媒体服务器」里已配置好的飞牛影视连接（不另行登录）。
- 入库事件里取 MoviePilot 的二级分类（`mediainfo.category`）或落地二级目录名，
  按你手动维护的映射找到对应飞牛站点，调用 `POST /mdb/scan/{guid}` 定向刷新。
- 飞牛站点名 → guid 每次运行时经 `/mediadb/list` 现拉，不写死。

## 配置

- **飞牛媒体服务器**：选择系统里已配置的飞牛影视（必选）。
- **延迟合并（秒）**：多次入库按站点去重合并后统一扫描。
- **站点映射**：每行一条，格式 `飞牛站点名或guid = 分类1,分类2,...`（逗号分隔，可用全角逗号）：

  ```
  电影=动画电影,华语电影,外语电影
  动漫=国漫,日漫
  国产=国产
  ```

  左边可填站点名或 32 位 guid；右边是 MoviePilot 的二級分类/二级目录名，一条站点可对应多个分类。
  `#` 开头为注释。站点名与 guid 见插件详情页（`/libraries`）。

- **未命中兜底**：跳过不刷，或全量扫描（`scanall`）。

## 说明

飞牛扫描接口只有「站点级」`/mdb/scan/{guid}` 和「全量」`/mdb/scanall` 两级，没有目录级；
因此映射目标是"站点"（一个站点可覆盖多个二级目录），命中后只扫对应站点。
